# Chinese dictation simulator

Practice tool for a 听写 (dictation) on *汉语教程（第3版）第一册·上*, Lesson 1 (Communication + characters) and Lesson 3 Exercises 1–3 (tones, 不 tone sandhi, distinguishing sounds).

- **Study:** the spelling rules and every item, click to hear.
- **Practice:** hear an item, write it, type it to check. Explains which rule a mistake broke. Misses come back.
- **Mock test:** 20 items, read twice, timed, book hidden.
- **Errors:** your missed items, kept in your browser.

Audio was generated with a neural text-to-speech voice. The textbook itself is not included; use "Open PDF…" to view your own copy beside the drill (it is not uploaded anywhere).
